# Task 1 - Traffic Image Preprocessing

## Objective

The purpose of this task is to prepare raw traffic images before sending them to an AI model.

Raw images can have different sizes and pixel ranges.

The preprocessing pipeline converts them into a consistent format.

## Workflow

```text
Original Image
      |
      v
Read using OpenCV
      |
      v
Resize / Letterbox
      |
      v
640 x 640 Image
      |
      v
Normalize Pixel Values
      |
      v
Ready for Model Input
```

## Image Loading

The image is loaded using:

```python
cv2.imread()
```

---

## Letterboxing

Letterboxing resizes the image while preserving its original aspect ratio.

Instead of stretching the image, empty areas are padded.

The final size becomes:

```text
640 x 640
```

This is useful because object detection models usually require fixed input dimensions.

---

## Normalization

OpenCV image pixels normally range from:

```text
0 to 255
```

The image is converted to floating-point values:

```python
normalized = image.astype(np.float32) / 255.0
```

The new range becomes:

```text
0.0 to 1.0
```

This improves compatibility with machine learning models.

# Task 2 - Industrial Defect Detection

## Objective

This task demonstrates how color information can be used to isolate industrial defects.

For example, rust on metal can have a specific color range.

---

## BGR to HSV Conversion

OpenCV loads images in BGR format.

The image is converted using:

```python
hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)
```

HSV separates image information into:

- Hue
- Saturation
- Value

Hue represents the actual color.

This makes color filtering easier than using BGR directly.

---

## LAB Conversion

The image is also converted to LAB color space.

```python
lab = cv2.cvtColor(image, cv2.COLOR_BGR2LAB)
```

LAB contains:

- Lightness
- Green to Red component
- Blue to Yellow component

It is useful in industrial image processing because color information is more independent from lighting.

---

## Color Thresholding

A lower and upper HSV range is defined.

Example:

```python
lower = np.array([5, 70, 40])
upper = np.array([25, 255, 255])
```

A mask is created:

```python
mask = cv2.inRange(hsv, lower, upper)
```

Only pixels inside the selected range remain white.

Other pixels become black.

---

## Defect Isolation

The binary mask is applied to the original image using:

```python
cv2.bitwise_and()
```

This produces an image containing only the selected defect region.

# Task 3 - Medical Image Edge Detection

## Objective

The purpose of this task is to remove noise and extract boundaries from a medical image.

The pipeline compares Gaussian and Median filtering.

---

## Gaussian Blur

Gaussian Blur smooths an image using a weighted kernel.

```python
cv2.GaussianBlur()
```

It is effective for reducing Gaussian noise.

---

## Median Filter

Median filtering replaces each pixel with the median value of nearby pixels.

```python
cv2.medianBlur()
```

It is especially effective for salt-and-pepper noise.

---

## Sobel Edge Detection

Sobel filtering calculates image gradients.

Horizontal edges:

```python
cv2.Sobel(..., 1, 0)
```

Vertical edges:

```python
cv2.Sobel(..., 0, 1)
```

The X and Y gradients are combined to calculate the total edge magnitude.

---

## Canny Edge Detection

Canny Edge Detection produces thin and clear object boundaries.

```python
cv2.Canny()
```

It uses two threshold values.

The output is compared across:

- original image
- Gaussian blurred image
- Median filtered image

The number of detected edge pixels is also calculated for quantitative comparison.

# Task 4 - YOLO Model Benchmarking

## Objective

The purpose of this task is to compare a lightweight YOLO model with a larger model.

The two models used are:

```text
YOLOv8n
YOLOv8m
```

---

## YOLOv8n

YOLOv8 Nano is lightweight and fast.

It is useful for:

- edge devices
- real-time detection
- systems with limited hardware

---

## YOLOv8m

YOLOv8 Medium is larger and usually provides stronger detection performance.

However, it requires more computation.

---

## Benchmark Process

Both models receive the same test image.

For every detected object, the system extracts:

```text
Bounding Box
Class ID
Class Name
Confidence Score
```

The bounding box coordinates are:

```text
x1, y1, x2, y2
```

---

## Latency Measurement

Inference time is measured using:

```python
time.perf_counter()
```

The total time is converted to milliseconds.

This allows the two models to be compared in terms of speed.

---

## Comparison Metrics

The benchmark compares:

- inference latency
- total number of detections
- detected class counts
- average confidence score

This demonstrates the tradeoff between speed and model complexity.

TARGET_CLASSES = {

## Confidence Filtering

Only detections above the selected confidence threshold are accepted.

## Class Counting

total_count = sum(counts.values())

This simulates an automated shelf inventory monitoring system.

# Task 6 - Smart Security Intrusion Detection

## Objective

This task demonstrates how an AI surveillance system can detect whether a person enters a restricted area.

The restricted area is represented using a polygon.

---

## Region of Interest

A polygon is defined using NumPy coordinates.

Example:

```python
roi_points = np.array([
    [300, 200],
    [700, 200],
    [800, 700],
    [200, 700]
])
```

This polygon represents the restricted zone.

---

## Person Detection

YOLO runs on the surveillance image.

Only objects with class ID:

```text
0
```

are processed because COCO class ID `0` represents a person.

---

## Bounding Box Centroid

For every detected person, the center point of the bounding box is calculated:

```python
cx = (x1 + x2) // 2
cy = (y1 + y2) // 2
```

---

## Point in Polygon Test

The centroid is checked using:

```python
cv2.pointPolygonTest()
```

If the point is inside the ROI:

```text
INTRUSION DETECTED
```

Otherwise:

```text
AREA SECURE
```

The ROI becomes red when an intrusion occurs and green when the area is secure.

# Task 7 - Real-Time Webcam Multi-Object Detection

## Objective

This task extends YOLO object detection to a live webcam feed.

The application continuously reads webcam frames and runs inference.

---

## Webcam Capture

The webcam is opened using:

```python
cv2.VideoCapture(0)
```

Frames are continuously captured inside a loop.

---

## Real-Time Inference

Every frame is passed to YOLO.

The detected objects are displayed using:

- bounding boxes
- class labels
- confidence scores

---

## FPS Calculation

Frame rate is calculated using the time difference between frames.

```python
fps = 1 / (current_time - previous_time)
```

The FPS value is displayed on the live video.

This shows how fast the system is processing frames.

---

## Keyboard Controls

The script includes keyboard controls.

```text
Q = Quit
S = Save Frame
```

Pressing `S` stores the current detection frame inside:

```text
outputs/saved_frames/
```

Pressing `Q` stops the application.

---

## Resource Cleanup

When the application stops, the webcam is released using:

```python
cap.release()
```

All OpenCV windows are closed using:

```python
cv2.destroyAllWindows()
```

# Task 8 - Edge-Triggered Surveillance System

## Objective

Task 8 extends the real-time YOLO system into an automated security event logger.

The system automatically saves evidence when a high-priority object is detected.

---

## High-Priority Classes

Example target classes are:

```python
HIGH_PRIORITY_CLASSES = {
    0: "person",
    67: "cell phone"
}
```

---

## Confidence Threshold

The system only generates an alert when:

```text
confidence > 0.65
```

This reduces low-confidence events.

---

## Event Detection Workflow

```text
Webcam Frame
     |
     v
YOLO Detection
     |
     v
Is Target Class?
     |
     +---- No ----> Continue Monitoring
     |
    Yes
     |
     v
Confidence > 0.65?
     |
     +---- No ----> Continue Monitoring
     |
    Yes
     |
     v
Save Snapshot
     |
     v
Write Log Entry
     |
     v
Display Security Alert
```

---

## Snapshot Saving

When an event occurs, the frame is saved using a timestamp.

Example:

```text
20261004_173512.jpg
```

Snapshots are stored in:

```text
alerts/
```

---

## Event Logging

Each event is recorded in:

```text
logs/events.log
```

The log contains:

```text
Timestamp
Class Name
Confidence
Bounding Box
```

Example:

```text
Timestamp,Class Name,Confidence,Bounding Box
2026-10-04 17:35:12,person,0.921,"125,63,522,477"
```

---

## Cooldown System

Without a cooldown, the same person could trigger hundreds of alerts because the webcam processes many frames every second.

A cooldown is therefore applied.

Example:

```python
ALERT_COOLDOWN = 5
```

This means the system waits five seconds before saving another alert.
